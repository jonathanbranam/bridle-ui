A "Time" page:
- Range picker: this week, last 4 weeks, custom.
- Group by project, agent or machine.
- (a) Totals per day and per week: stacked bars, plus the human's total (union) as its own line/bar.
- (b) One day: per-session timeline with simultaneous conversations shaded; start, stop, total, peak concurrency.
- (c) Time of day: hour-by-hour chart, filtered to weekdays, weekends or chosen days of the week.
- Choices persist in the browser (localStorage).
- Times in US Eastern.
Data: /api/v1/interactions/report, /day, /hours (generated gateway types, as the API client already does).
Tests: vitest for the bucketing/filter logic and persistence. Acceptance: npm run check passes.
