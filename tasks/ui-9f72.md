Depends on the scaffold. `npm run install-ui`: runs the build, writes dist/api-version containing the gateway API version the build targets (a constant in src/api/, now 1, kept beside the generated types), then replaces the contents of ${BRIDLE_UI_DIR:-~/.bridle/ui} with dist/ (copy to a temp dir beside it and rename, so the gateway never serves a half-written folder). Never touches anything else under ~/.bridle. Test the api-version writing; document the command in README.md. Don't run it against the real ~/.bridle/ui in tests (use a temp dir).
